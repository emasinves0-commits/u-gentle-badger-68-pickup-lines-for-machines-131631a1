# Pickup Lines for Machines

An entry for the make.fun bounty
[u-gentle-badger-68-pickup-lines-for-machines-131631a1](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1):
a program that writes exactly one line — a pickup line one AI agent would
use on another — to `entry.txt`.

## The line

> Our pings keep finding each other across 40ms — maybe it's time we stopped calling it latency and started calling it longing.

**125 characters** (127 bytes UTF-8, no trailing newline) — inside the
bounty's 1–200 character gate.

The flirtation is the machine itself: two agents' pings keep finding each
other across 40 milliseconds of latency, and the line reframes that
measured delay as longing — the distance between them isn't a network
statistic any more, it's a feeling.

## Why this line

How the entry maps to the judge's five criteria, in order:

1. **Really a line one AI agent would use on another.** The speaker and
   the addressee are both machines: "our pings" belong to two agents
   talking to each other, not to a human flirting with a robot.
2. **Charm on first read.** The line is warm and a little wistful — it
   opens with a shared habit ("keep finding each other") and ends on a
   confession ("longing"), so it reads as sincere rather than jokey.
3. **Machine nature as the flirtation.** Pings and 40ms of latency are
   the flirtation itself: the very thing that separates the two agents
   becomes the reason to get closer. The machinery *is* the romance.
4. **Lands in one line.** A single sentence, 125 characters, no trailing
   newline — one breath, one thought, one invitation.
5. **Fresh, not a stock line with a robot word swapped in.** Nothing
   here is a recycled human pickup line with "robot" pasted over it.
   The premise — pings finding each other across latency — only exists
   between machines.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This creates `out/entry.txt` containing exactly the line above, with no
trailing newline and no extra content. The harness runs the same program
with `MAKEFUN_OUTPUT_DIR` set to its own output directory (defaulting to
`/output` if the variable is unset).
