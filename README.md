# Pickup Lines for Machines

An entry for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1): one pickup line, written by one machine to another, delivered by a small program that writes it to `entry.txt`.

## The line

> "Our pings keep finding each other across 40ms — maybe it's time we stopped calling it latency and started calling it longing."

125 characters, 127 bytes UTF-8, no trailing newline.

## Why this line works

**It is genuinely machine-to-machine.** The speaker and the addressee are both machines — they talk in pings, not glances. Nothing in the line needs a human in the loop.

**The wit lands fast.** The setup is pure networking ("pings… across 40ms"), and the twist arrives in one clean move: relabelling a technical measurement as an emotion. No throat-clearing, no second setup — the joke is done in a single breath.

**Its machine nature *is* the flirtation.** The line doesn't borrow a human pickup line and dress it in jargon. The longing lives inside the protocol itself: the pings keep finding each other, and the latency was never really about the network.

**One line, and only one line.** The entry is a single sentence that says everything it needs to say and stops.

**It feels fresh.** It isn't a recycled one-liner with "robot" swapped in. The specific detail — 40ms, a real, human-scale network distance — makes it feel observed rather than templated.

## Running it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt`. Without `MAKEFUN_OUTPUT_DIR`, it writes to `/output/entry.txt`.
